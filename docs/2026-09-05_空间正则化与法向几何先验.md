## 1 动机：两类残留伪影

语义监督只在 **teacher 粗网格池化** 尺度进行（`get_loss_dict` 中 `adaptive_avg_pool2d` 到教师 `[gH,gW]`），无法约束高频逐像素一致性 → **物体内部椒盐碎斑**；物体边界常有**半透明"雾状高斯"**使语义越界。

抛光目标：碎斑抹平（但**不跨物理边缘**）、边缘雾状高斯剃除、语义锁回物理边界。两条路：训练期 loss 正则（改场）+ 查询期几何先验（改判）。

## 2 方法 A：两个训练期正则（默认 OFF）

### 2.1 Depth-aware TV

```text
term = num/den，逐像素把 feat 向量 L2 归一后（与蒸馏同规约，尺度不变、代价有界 O(0..4)）
num  = Σ 相邻(上下/左右)像素 squared-L2 差 × w
w    = exp(-(Δd)²/2σ²)，Δd 用 feature pass 同渲染的期望深度(ED)，两端 alpha>0.5 才计
σ    = sem_tv_depth_sigma，场景尺度单位（Replica 米制直接设 0.1m）
```

只平滑**深度连续平面内**的椒盐噪声；在深度台阶（物理边缘）处 w→0，**不跨边抹糊**。梯度只进 `sem_features`（feature pass 已 detach 几何/透明度）。

### 2.2 Opacity Entropy

```text
H(a) = -(a log a + (1-a) log(1-a))，a = sigmoid(logits)
logit 空间用 softplus 实现：log a = -softplus(-z)、log(1-a) = -softplus(z)
return H.mean()，∈[0, ln2]
```

把每高斯 alpha 向 0/1 极化；半透明边缘高斯被推向 0 后由基础 Splatfacto cull（`cull_alpha_thresh=0.1`）收割。梯度对 logit `a(1-a)·ln((1-a)/a)`：雾带 a≈0.1-0.25 最强；a=0.5 是**不稳定极大点**（Adam 可逃逸，非停驻）。**不能用** `BCE_with_logits(z, sigmoid(z).detach())`（detach 目标杀死梯度）。极化与 `reset_alpha_every=30` 每 3000 轮把 alpha 压回 0.2 的行为自限。

### 2.3 模型接线与关键事实

- 新模块 [semsplat/losses.py](../semsplat/losses.py)（纯 CPU torch 函数，不 import 模型 → 可独立单测）。
- [semsplat/semsplat_model.py](../semsplat/semsplat_model.py) 三处：
  1. config 字段（teacher 块之前，全部默认 OFF）：`sem_tv_mult=0.0 / sem_tv_depth_sigma=0.1 / sem_tv_eps=1e-3 / opacity_entropy_mult=0.0 / opacity_entropy_start_iter=1000`；
  2. feature pass：`sem_tv_mult>0` 时切 gsplat `render_mode="RGB+ED"` 并在 rasterization 传 `channel_chunk = sem_K+1`（防 33 通道被默认 32 chunk 拆成两 kernel）；ED 把**已 alpha 归一**的 view-space z 追加为最后通道，故 `feat_map=feat_render[...,:K]/alpha` 不变，深度存 `outputs["sem_feature_depth"]`；
  3. `get_loss_dict`：熵项紧跟 `not self.training` 返回后（语义阶段门之前，RGB-only 早期也生效）；TV 项在 `semantic_loss` 写入后。
- `sem_K`、`channel_chunk` 逻辑见 [semsplat/semsplat_model.py:329-360](../semsplat/semsplat_model.py#L329)；两钩子见 [semsplat/semsplat_model.py:484-549](../semsplat/semsplat_model.py#L484)。
- 单测 [tests/test_regularizers.py](../tests/test_regularizers.py)：熵值/梯度/Adam 双峰极化；TV 恒值=0 / 单椒盐>0 / 深度台阶≈0（边缘保护）/ 全未覆盖=0 / 无 NaN；config 默认 OFF 门；GPU RGB+ED parity（ED 深度 == premultiplied D-mode / alpha，确证已归一）。
- 跑法：`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest tests/test_regularizers.py -q`（venv 里残留 ROS `launch_testing` 与 pytest hook 冲突，必须禁插件自载）。

## 3 方法 B：查询期法向几何先验（零训练）

脚本 [scripts/orb_slam/eval_geo_prior.py](../scripts/orb_slam/eval_geo_prior.py)（`eval_miou_room.py` 同基准 + `--prior norm`）：

```text
1. 栅格化高斯世界坐标 means -> 每像素期望位置图（scoring.rasterize_class_scores）
2. 中心差分恢复 surface normal，朝相机定向（flip 使 n·(cam-pos)>0）
3. nx = n·up（world up 默认 (0,1,0)），几何仲裁仅作用于 stuff：
      normal·up < -cos_thr  -> ceiling 软分 +delta
      normal·up >  +cos_thr -> floor   软分 +delta
      |normal·up| < horiz_thr -> wall（默认 0 = 从不降级 stuff）
4. 仅当该像素文本 argmax 已是 {wall,floor,ceiling} 之一才仲裁
   -> 桌子/地毯/沙发等已判到物体类的像素永不改判
```

与 ORB-SLAM + 同一 3DGS 的部署端同构，可原样复用。默认 `geo_cos_thr=0.85 / geo_delta=2.0`。

## 5 已知局限（诚实边界）

1. **ceiling→wall 塌缩根源在文本↔视觉不对齐**：蒸馏目标 = 教师 CLIP 视觉特征，白天花板视觉本就"墙样"，loss 权重压不掉；几何（查询期或训练期）是唯一可用的修正信号。plant/clock/desk ≈0 同理属教师/文本召回问题。
2. sofa 略降、wall/floor 在加先验后小幅回吐 —— 属于改判/极化的系统性代价，已在 §4 量化。
3. 高斯数 −44% 后重建画质未正式 ns-eval 对基线（未做 PSNR/SSIM 对比；训练 PSNR ~35.5）。如需可补跑。
4. 训练期 bake-in 尚未实现（§7）；如做，需注意把 wall/floor/ceiling 写死进目标 = 闭集偏置（换场景/prompt 集需谨慎），且与教师错误视觉目标对抗、需调权。
5. 测试集 `tests/test_sam_clip_teacher.py::test_amg_masks_cover_like_grid_on_office0_frame` 一处既有失败与本次改动无关（AMG 教师侧待办）。

## 7 待办 / 悬而未决：法向能否烤进训练？

**现状结论**：查询期先验已拿走几乎全部收益（0.255、零训练）。法向**可以**烤进训练，且技术上成立 —— 方案是"几何仲裁的教师目标替换"：
1. 几何门：feature pass 已渲染 ED 深度（TV 在用），或把高斯 means 当颜色列顺带栅格化 → 每像素 `normal·up`；
2. 文本门（关键，防误伤桌子/物体）：教师网格分辨率算教师视觉对 13 prompt 余弦，仅 `stuff-argmax∈{wall,floor,ceiling}` 才可被几何改判；
3. 替换：geometry 说 ceiling/floor 且教师判 wall 的格子 → 蒸馏目标换成该 stuff 词的 CLIP 文本嵌入。

价值：部署端（如 D435i 自录）**推理不再需要仲裁**、TV/邻域传播的是修正后的类、跨帧一致更好；代价：一次重训 + 调权 + stuff 词写死进目标的闭集偏置。**是否实现未拍板。**
