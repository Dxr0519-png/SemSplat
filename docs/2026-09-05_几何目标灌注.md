## 0 结论速览

**Arm B′（ceiling 灌注单臂，mult 1.0，20k）已跑完评估（纯 argmax 50 帧）**：

1. **天花板是修好了，但以"墙被灌进 ceiling"为代价**：ceiling IoU **0.005 → 0.280**，超过 hinge A′ 0.217 与 geo oracle 0.249。hinge 的"停泊漂移→tv/door"也消失（tv/door FP-on-stuff 969k/926k，回到 reg 788k/1.32M 量级，远低于 A′ 1.98M/2.33M）——负向漂移确实被消除。
2. **但 ceiling 文本是"白面吸引子"，漏进整面白墙**：injCeil 把 ceiling 预测到 **2,596k 个 GT-wall 像素**（A′ 只有 13k），另有 sofa 140k/table 80k/rug 57k 等 ~923k 溢出。ceiling 0.280 是靠这 2.6M 假阳性撑起来的（GT ceiling 真阳 1,519k；FP≈3.5M）。
3. **净效果 mIoU 0.196 < reg 0.240、geo 0.255**：chair 0.865→0.699、wall 0.435→0.245、table 0.648→0.490、lamp 0.178→0.042、rug 0.200→0.102 等全线下滑。机制解释：**共享 feature_head + TV 耦合下，对 ~17% 格连续 20k 步"正拉到 ceiling 文本点"建立一个吸引盆地，白墙（教师特征本就接近白 ceiling 文本）被整体拖入**。geo oracle 只在**查询期**重标 down-facing、竖向墙不动 → 无此问题（wall 0.407、mIoU 0.255 仍是当前最优）。
4. **待拍板**：见 §6。候选 = 调低 `sem_inject_mult`（弱拉，只让锁定格落 ceiling、不把墙拖进盆地）重跑，或放弃训练期灌注、采信查询期 geo 先验，或两者结合。

## 1 机制

### 1.1 问题（为什么放弃 hinge）

上一轮 20k 双臂证明负向排斥能修 ceiling（纯 argmax ceiling 0.005→0.217），但 hinge 只负责"推离 wall"，推够 margin=0.2 就停——被推的像素落在哪不受控，实测大量**停靠漂移到 tv/door/rug 文本**（FP-on-stuff 翻倍、tv/door/rug IoU 被压）。负向排斥给的是"不是墙"，给不了"是天花板"的明确终点。

### 1.2 做法：把"教师视觉特征"目标换成"CLIP 文本向量"

推理 argmax 量的正是 `pred_feature @ text_emb`（特征与文本的相似度）。因此**直接把被证伪格的蒸馏目标从教师图像向量换成固定 CLIP 文本向量**（L2 归一、与教师同 CLIP 联合投影空间），`feature_head` 的 pred 被**正拉向该文本点**——训练目标模态 = 推理目标模态，收敛后 argmax 稳定落该词，无 margin、无停靠漂移。

**天花板塌缩 → 强制文本灌注**：触发 `nx < -cos_thr`（朝下）∧ 教师受限 argmax ∈ {`plain room wall`} → 该像素蒸馏目标替换为 **`flat white ceiling`** 的 CLIP 文本向量。
**墙面碎斑 → 平面强制归化**（默认开但首臂用 CLI 关）：触发本地平面拟合"共面/极平"（`cell_plane_flatness`）∧ 教师受限 argmax ∈ {`television screen,door,table lamp,wall clock`} → 该像素蒸馏目标替换为 **`plain room wall`** 的 CLIP 文本向量。

**与 hinge 版的关键差异**：
- 被锁格**不再**正蒸馏 ×0、也**不再**有独立 hinge loss；它们只是把 `semantic_loss`（cos/l1/mse，同一 `semantic_loss_type`）的**目标**换掉，**继续走正常蒸馏正拉**。
- 锁定格与教师格的 loss **分域取均值**再加权（注入格 `sem_inject_mult`，默认 1.0）：注入格是小且固定的子集，不分摊到教师格数量里被稀释，保证"强拉"。

**（用户拍板记录）** 这偏离上一版"类别词永不作正目标、只作排斥锚"的开放词汇纯洁性约束——类别词现作为**注入目标**使用。触发仍是纯几何（朝下/共面），类别词只在几何已证伪教师读数之后才作为终点被引用。

## 2 已定设计决策（用户拍板）

1. **保留几何骨架、只改 loss 语义**：复用世界坐标光栅 `sem_feature_pos`、`sem_inject_cam_center`、4 个 regime CSV + 2 veto、显存 CLIP 塔文本缓存 `_ensure_inject_text`、几何单测；删除 hinge 专属（`hinge_contrastive`、margin、`sem_contrast_*` 命名）。
2. **先跑 ceiling 灌注单臂**（flat regime OFF），20k，验证后决定是否碰 flat。

### 2.1 命名从 `sem_contrast_*` → `sem_inject_*`

机制已不是 contrastive，字段全量改名（config/helper/metrics key），默认仍全 OFF ⇒ OFF 逐位同基线语义蒸馏。删：`sem_contrast_margin`、hinge。改：`sem_inject_mult`（注入格权重，非 hinge 权重）。

### 2.2 Config 字段（默认全 OFF）

| 字段 | 默认 | 说明 |
|---|---|---|
| `sem_inject_enabled` | False | 总开关；OFF ⇒ 无额外光栅、无目标替换、逐位同基线 |
| `sem_inject_start_iter` | -1 | <0 ⇒ 同步 `semantic_start_iter`（200） |
| `sem_inject_mult` | 1.0 | 注入格蒸馏权重（相对教师格 1.0；调大=更强拉） |
| `sem_inject_up` | (0,1,0) / `sem_inject_cos_thr` | 0.85（Replica +Y up，与 eval_geo_prior 对齐） |
| `sem_inject_ceiling_enabled` | True / `ceiling_down_frac` 0.5 | 天花板 regime |
| `ceiling_mask_prompts_csv` | `"plain room wall,floor,flat white ceiling"` | 受限 argmax 词表 |
| `ceiling_veto_prompts_csv` | `"plain room wall"` | 朝下不可能词（argmax∈此 & 朝下 ⇒ 注入 ceiling） |
| `ceiling_target_prompt` | `"flat white ceiling"` | 注入的文本向量 |
| `sem_inject_flat_enabled` | True | 平斑 regime（首臂 CLI False） |
| `flat_tol_m/min_covered_frac/min_covered_px/spread_ratio` | 0.01/0.5/8/0.05 | 平面拟合门 |
| `flat_mask/veto_prompts_csv` | `"television screen,door,table lamp,wall clock"` | 平斑词表=veto |
| `flat_target_prompt` | `"plain room wall"` | 注入的文本向量 |

## 3 代码接线与产物（相对 hinge 版的改动）

- `semsplat/losses.py`：
  - **删** `hinge_contrastive`。
  - `teacher_veto_mask` 返回值从 `(is_veto, top_vec)` 精简为 `is_veto`（顶格向量不再被当排斥锚，无消费者）。
  - **加** 纯函数 `inject_target(tgt_n, c_lock, f_lock, ceil_vec, wall_vec) → (tgt_out, inject)`：非锁定行逐位保留教师向量；`f_lock` 行→wall_vec、`c_lock` 行→ceil_vec（**撞格 ceiling 优先**）；`inject = c_lock|f_lock`。CPU 可测。
- `semsplat/semsplat_model.py`：
  - config `sem_contrast_*`(17) → `sem_inject_*`(18, 增两 target + mult，删 margin)。
  - `self._contrast_text` → `self._inject_text`；`_ensure_contrast_text`→`_ensure_inject_text`（并集 = 2 mask + 2 veto + **2 target prompt**）；加 `_inject_vec(prompt)`。
  - `get_outputs`：`contrast_on` 读 `sem_inject_enabled/start_iter`；`outputs["sem_contrast_cam_center"]` → `["sem_inject_cam_center"]`；`sem_feature_pos` key 名不变。
  - `get_loss_dict`：触发器逐位同 hinge 版（`teacher_veto_mask` + `cell_down_fraction` / `cell_plane_flatness`，全 detach）；`tgt_eff, inject_mask = inject_target(...)`；`loss_eff` 对 `tgt_eff` 算；`semantic_loss = mean(loss_eff[teach]) + sem_inject_mult·mean(loss_eff[inj])`（空域返零）；TB metric `sem_inject_frac`。OFF ⇒ `inject_mask=None` ⇒ 原单行均值路径。
- `tests/test_contrastive_rejection.py` → **`tests/test_geom_inject.py`**：几何测试全部保留；删 hinge 行为/Adam 两测；`teacher_veto_mask` 单测改单返回值；加 `inject_target`（无锁逐位保留/有锁替换/撞格 ceiling 优先/L2&NaN）；config-off guard 改断言 `sem_inject_*`。
- 复用不动：`encode_text_prompts(clip_model=)` 显存塔复用、`scripts/orb_slam/eval_miou_room.py`、`measure_thing_recall.py`。
- 产物：hinge 版 run/评估保留为对照（`outputs/..._negc_aprime`、`results/orb_ate/negc_aprime`）。

## 6 风险与决策点（含 B′ 实证更新）

1. **【B′ 实证】注入是把双刃剑：正拉建立"白面吸引盆地"**。风险 1 兑现了但比预想严重——ceiling 文本对**白色竖墙**也是吸引子：共享 `feature_head` + TV 耦合下，把 ~17% 格连续 20k 步正拉到 ceiling 文本点，最终 2.6M 个 GT-wall 像素被预测成 ceiling（ceiling 0.280 靠 FP 撑、wall 0.435→0.245）。hinge 的"停泊漂移"是**消失**了，但负向排斥的漂移只发生在被推格子上；**正向吸引的漏出在共享参数上全局扩散**。geo oracle 只在查询期重标 down-facing、竖向墙零改动 → 0.255 依旧最优。
   → **下一步候选（未跑，需拍板）**：a) **调低 `sem_inject_mult`**（如 0.1–0.3）弱拉——只让锁定格落 ceiling、不再把相邻白墙拖进盆地，ceiling-only 20k 重测；b) 灌注同时**给竖向白墙反向锚定 wall 文本**（镜面对称，两边都钉死，防墙滑向 ceiling）——比 (a) 激进但更接近"每个白面都有自己的文本吸引子"；c) **放弃训练期灌注，采信查询期 geo 先验**（0.255 已被证明、零漏出、零训练成本）；d) (a)+(c) 组合。
2. **家具底面误灌注**：B′ 里 GT sofa/table/rug/organizer 共 ~923k 像素被预测成 ceiling——部分是白面溢出（同 wall），部分是底面/近顶真误读；调低 mult 应同时缓解，是否需收紧 veto 待 (a) 后再看。
3. **flat→wall 已知伤真 flush 物体**：首臂 flat OFF 规避；flat 臂真 tv recall 崩是预期，需另行拍板。
4. **文本/图像模态分布差**：注入格拉向文本、教师格拉向图像，CLIP 联合空间同域但不同位；B′ 表明这个"双目标"是墙漏出的温床——低 mult 只影响锁定格邻近，可缓解。
5. **OFF 逐位一致**：改名 + helper 改名动了大量行；`inject_mask=None` 分支保留基线均值路径（数值同旧），config-off 单测保证。
