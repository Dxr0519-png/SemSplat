# DINOv2 融合教师（`teacher_kind: dinoclip` v3 = SAM 保真 + DINO 兜底）

日期：2026-09-05 · 状态：**已回退 —— 全部代码改动已取消，本文档仅为实验记录（保留盘上产物作证据）**

一句话：dinoclip v3（SAM-first，DINO 只兜底空白区）office0 6k mIoU **0.169**，修回了 v2 区模态覆写造成的
家具对象失分（sofa .099→.233、chair .520→.664、table .411→.494），但 6k 等预算仍 < samclip-AMG **0.187**
（差在 sofa/table 残余 −0.10 级）。整条 dinoclip 线 v1/v2/v3 从未超 samclip-AMG，用户已决定**取消全部 DINO
代码改动、仅留本文档**：`semsplat_model.py`/`sam_clip_teacher.py` 已 `git restore` 回 pre-DINO 提交，
`dino_clip_teacher.py`/`sam_dino_probe.py`/`dino_fuse_probe.py`/`gallery_dinoclip.py`/`precompute_dino_dense.py`/
`test_dino_clip_teacher.py` 全部删除，`teacher_kind: dinoclip` 槽位不再存在。samclip-AMG 维持最强教师/默认不改。
下方机制/探针/结果均为回退前实测，仅作档案。

## 动机

v2 把每个 DINO 区的 **modal 对象覆写整区**（`region_objects` 广播）——含 SAM 已高置信确定的 cell 与
minority 对象 cell。office0 6k 逐类显示失分集中在占大视场的家具对象（sofa/chair/table），机理 = DINO 区
GT purity ~0.88 非 1：区多数把这些 SAM 已正确判定的 cell 重涂成区多数。v3 **反转为 SAM-first**：

```
SAM 层（不可变——DINO 永不覆写）
  SAM-AMG 掩码 + 上下文裁剪 → e_k [K,512]               (samclip 语义源，前端共用)
  decided cell = 覆盖率 ≥ cell_anchor_frac(0.2) → 保留各自 SAM argmax
                 （"≥0.8 锁死"为其内蕴子集——保留全部 decided 更严格）
  blank cell    = 覆盖率 < 0.2（SAM 放弃）
DINO 区（τ 探针定 0.85，非"更严更好"）
  空白 cell 取同区 decided cell 的多数对象；蔓延 iff 区 decided / 区总 ≥ region_anchor_frac(0.4)
  （门: 防小 SAM 残片涂满大空白区）；门不过或区无 decided → 空白保持 cov 0（原兜底，被损失 mask 排除）
scatter: decided + 蔓延 cell 写 e_obj, cover 1；其余 0 + cover 0
```

与 samclip 差异 = 散射仍按 DINO 区（视角稳定）补 SAM 放弃区；与 v2 唯一算法差异 = **去掉整区广播**，
decided cell 不再被区多数改标 → v2 家具失分机理性消除。

已对齐（AskUserQuestion）：分层=保守（空白<0.2、中间带 0.2–0.8 保留 argmax）；蔓延源=区内全部 decided 多数；
保留区级门槛（默认 0.4，探针标定）；τ=探针定。

## τ / 蔓延门探针（office0 帧 0/50/200/290；cell 固定 0.2）

```

0.85  0.4 |   94 |   0.897 |  0.946 |   0.894 |   0.621   ← 默认 gate
```

dec_cov 0.897（SAM 不可变层）与 τ/门无关，且已 > v2 探针 cov_gt 0.872。**τ 不升**：区越碎、区 decided-majority

的直觉在此指标上不兑现，故默认 0.85。门 0.3–0.4 覆盖与 inp_pur 均 ≥ 0.5，取 0.4（0.3 仍挡 1-cell 残片 12% < 30%）。

### 结论（6k 等预算）

v3 **验证了机理假设**：v2 家具失分源于 DINO 区模态覆写 SAM 已确定 cell，SAM-first 修回 sofa/chair/table
大半（v2 0.136 → v3 0.169，+0.033）；chair 已到 samclip 水平，wall/tv/ceiling 持平或更优。但 **6k 仍未超
samclip-AMG**（0.169 < 0.187），残余差集中在 sofa/table 两对象（约 −0.10）：此时限制不再是"被覆写"，而是
14×14 decided/蔓延 对对象边界像素的身份精度不如 samclip 的 16px cell 池化。**samclip-AMG 维持最强教师/默认
不改**；`dinoclip` 槽位=v3 保留为可选（自录数据 SAM 覆盖稀疏时 DINO 兜底仍有价值）。6k 实测与探针均留档，
不凑正面。

## 风险与说明

1. **τ 反直觉**：探针明确 0.85 最优（蔓延纯度随 τ 单调降），未采纳"τ 更严更好"预设——若要在其他场景验证 0.90/0.95，
   先跑探针看 inp_pur。
2. **蔓延仍可能错**：inp_pur ~0.62（探针）是空白区的硬上限；蔓延门 0.4 挡小残片但非零泄漏。6k 差 sofa/table ~0.10 即身份限制。
3. 跨帧对象身份漂移仍靠 3D 聚合吸收（机制边界不变）；DINO 只补覆盖一致性。
4. 结果如实：v3 0.169 修 v2 但 < samclip 0.187；samclip 默认地位不变。

## 明确不做

- 不改变 512=CLIP 文本空间 / 下游查询 / mIoU；不加第二 head / 第二损失。
- 不恢复 v2 整区广播；不对全局 patch CLIP 做分区均值（v1 教训）。
- 不改 DINO 分辨率 / K=32 / sidecar 格式；不加 cell-strict-keep 旋钮（decided≥0.2 保留已强于 ≥0.8 锁死）。
