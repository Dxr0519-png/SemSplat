## 0 结论速览与当前实施决定

1. **天花板丢失是 CLIP 文本/视觉端对“同色平涂面”的表示瓶颈，不是欠拟合、不是代码 bug**：
   AMG 整平面掩码 + ctx 裁剪让 CLIP-Base 把 90% 属天花的平面读成 “wall”（floor↔ceiling
   图像余弦 0.85–0.93，全部文本余弦挤在 0.25–0.30）。到 20k 仍不恢复。
2. **查询时几何法向先验（不重训）可把它修回来**：以重建自身的世界坐标位置图求逐像素表面法向，
   `法向·up` 判面朝向——面朝下=天花板、面朝上=地板、竖直=墙，仅仲裁已判为 stuff 的像素。
   office0 · 20k AMG · 50 帧 P_old：**ceiling .025→.498，mIoU .194→.231，wall .383→.410**，
   物体类与 RGB 完全不动。
3. **叠加离线清理（激进档）进一步到 mIoU .286**（见 §3），但它依赖按场景调参、会吞小真物
   （clock/desk/plant），属渲染图表现层后处理。
4. **当前实施决定**（本会话定）：
   - **拟实施（新管线默认候选）**：查询时几何判向，作为语义查询链路的一步；前置条件 = 鲁棒估计
     世界 up（office0 已验证为 +Y；自录/ORB 无 GT 场景需先做自动估 up）。
   - **暂不纳入实施**：离线清理（`cleanup_sem_maps.py` / `semsplat/seg_cleanup.py`）。
     仅保留为评估与产物（数据/命令见 §3、§4），不在当前实施计划内。
   - 更彻底的根治（后续选项）：把几何约束前移进**训练监督**（ceiling/floor 直接对齐 CLIP 文本向量）。

## 1 根因：为什么天花板“识别不出来”

### 1.1 现象
| arm | ceiling IoU | mIoU |
|---|---|---|
| 旧 6k grid 教师（灰底裁剪） | .639 | .179 |
| 新 AMG+ctx 教师 6k / 20k | .013 / .025 | .187 / .194 |

20k 收敛后仍不恢复 → 非欠拟合。

### 1.2 教师层探针（训练前就错）
同一帧、同一批 GT 天花板 cell，只换教师配置（`/tmp/ceiling_probe.py`）：
| frame | grid+灰底 | AMG+ctx |
|---|---|---|
| 0 | 246/246 → ceiling | **245/246 → wall** |
| 48 | 606/606 → ceiling | 404 ceiling + **202 wall** |

### 1.3 元凶掩码
frame 0 天花板区域逐个 AMG 掩码查（`/tmp/ceiling_masks_probe.py`）：
- mask#4（24% 面积、99% 像素是天花板）→ ceiling .27 / wall .27（打平）
- mask#12（**39% 面积、90% 像素是天花板**）→ 最近文本 = **wall** .27 / floor .26

### 1.4 机制
新教师把天花板切成 1–2 块**完整大平面掩码**（这本身是优点），再走 ctx 裁剪：整片天花板锐利 +
下方真实墙/环境**强模糊**进同一窗口。CLIP-Base 对这种“大片同色室内平面+环境”的图，最近文本就是
**wall**——办公室天花板与墙同色，视觉端分不出“大平涂面是顶还是侧”。旧灰底裁剪只剩纯纹理、
抹掉环境，反而编码得离 “ceiling” 文本更近（歪打正着）。→ **必须几何判向，绕开 CLIP 视觉混叠**。

## 2 已做方案：查询时几何法向先验

新脚本 `scripts/orb_slam/eval_geo_prior.py`（与 `eval_miou_room.py` 同构，`--prior none|norm` 自对比，
schema 一致，可接离线清理）。

### 2.1 关键设计选择
- **不用“per-高斯高度”做天花板/地板门限**：重建点云含大量低透明 floaters（Y 散布 −2.8~+2.7，房间仅
  ±0.5），pred-ceiling/pred-floor 的高度分布被污染、高度阈值不稳（`/tmp/geo_probe.py`）。
- **改用“per-像素表面法向”**：只发生在可见像素上，floaters 不参与，鲁棒。纯查询时，不重训、不需要 GT 深度。

### 2.2 世界 up
GT 深度反投影验证 office0 **世界 +Y = up**（floor≈−0.46、ceiling≈+0.6、wall 居中，多帧稳定）。
注意：相机轨迹“图像顶方向”的平均会带偏航倾斜（~[0.09,0.97,−0.23]）——应用场景 up，别用轨迹姿态平均。

### 2.3 算法（每 eval 相机）
1. 复用 `scoring.rasterize_class_scores(model, cam, model.means)` → 光栅化高斯**世界坐标位置图** `[H,W,3]`。
2. 位置图中心差分 → `法向 ≈ cross(dP/du, dP/dv)`，翻转向相机（探针验证：天花板法向·up<0、地板>0；
   方向 sign 起初写反，用 GT 探针修过一次）。
3. `nx = 法向·up`。**仅当 CLIP argmax ∈ {wall,floor,ceiling}**（索引随 prompts 序，默认 4/5/6）：
   - `nx < −0.85`（面朝下，在上方）→ 给 ceiling 分 +Δ(2.0)
   - `nx > +0.85`（面朝上）→ 给 floor 分 +Δ
   - `|nx| < horiz_thr`（降级墙）默认 **0.0 关闭**（保守：永不把一个 stuff 标签降级，避免伤已正确的
     grid 型天花板）。
4. 物体类（table/rug/sofa 顶等平放面）因 argmax 不是 stuff → **一律不碰**。

### 2.4 结果（P_old · 50 帧 `seq 0 6 294`）
| arm | none wall/floor/ceiling | mIoU | norm wall/floor/ceiling | mIoU |
|---|---|---|---|---|
| **20k AMG** | .383 / .042 / .025 | .194 | **.410 / .034 / .498** | **.231** |
| 6k AMG | .412 / .036 / .013 | .187 | .373 / .025 / .184 | .196 |
| 6k grid(旧基) | .372 / .017 / .639 | .179 | .317 / .022 / .557 | .168 |

- 混淆行（20k，ceiling 行）：none 93.4%→wall / 2.6% ceiling → norm 35.5%→wall / 60.4% ceiling。
- 阈值扫描：cos 0.85 最优（0.7/0.55 天花板微升但墙掉更多，mIoU 不涨）。

### 2.5 边界（写入记录，别误读）
1. **floor 仍弱**：主误读是 rug(32.6%)/door(16.5%)——与地板同几何/非 stuff，仲裁不碰。需更强文本或骨干。
2. 天花板仍有 ~35% 在墙：位置图噪声/边界处，夺回与伤墙成本相同。
3. **依赖重建质量**：对重建好的模型生效（20k 大赚、6k AMG 仍 +.009）；对欠拟合旧 6k grid（CLIP 本来就对、
   几何又噪）为负。逻辑：“几何 vs CLIP 文本谁更可靠谁说了算”，新管线（AMG + 足迭代）应默认开。
4. up 是显式给定并验证的；接 ORB/自录无 GT 场景需先自动估 up（轨迹/惯性/平面拟合）。

## 3 评估性叠加：离线清理（激进档）—— 暂不纳入实施

`cleanup_sem_maps.py`（`semsplat/seg_cleanup.py`）在**已渲染 argmax 图**上清“嵌在墙/天花/地板宿主里的小
wrong-class 岛”→并入宿主 + 全局 merge-tiny。与几何先验正交：几何修**整片** stuff 误读，清理削**碎斑 FP**。

参数（激进）：`--wall-classes 4 --ceiling-classes 6 --extra-host-classes 5 --min-area-frac 0.002 --merge-tiny`
（宿主=墙/地板/天花；0.2%≈614px；操作只写 `--out-dir`，不回写原 npz）。geo dump 的 prompts.json 需先补
`colors` 键；wall 用显式索引（子串会撞 `wall clock`）。

统一口径（20k AMG · 50 帧 · P_old）：
| class | base(none) | geo(norm) | geo+清理 |
|---|---|---|---|
| sofa | .493 | .493 | .587 |
| chair | .632 | .632 | **.791** |
| table | .428 | .428 | .571 |
| wall | .383 | .410 | .458 |
| floor | .042 | .034 | .046 |
| ceiling | .025 | **.498** | **.576** |
| lamp | .085 | .085 | .167 |
| door | .107 | .107 | .121 |
| tv | .125 | .125 | .148 |
| rug | .154 | .154 | .231 |
| clock | .001 | .001 | .000 |
| desk | .043 | .043 | .026 |
| **mIoU** | **.194** | **.231** | **.286** |

- 收益主要=削物体类散布在 stuff 面的 FP 碎斑（chair/table/lamp/tv/rug 抬升）；ceiling .498→.576。
- **代价**：≤0.2% 面积的小真物（clock/desk/plant 弱类）被并入宿主，recall 略降；参数需按场景调
  （宿主集合、面积阈、是否 merge-tiny），并可能吞靠近大平面的小对象。
- **决定**：效果已验证、产物保留，但**暂不纳入当前实施计划**（见 §0-4）。

## 5 复现命令
```bash
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
CFG=outputs/office0_320_sam20k_amg/office0_est320_ns/semsplat-replica/2026-09-04_171318/config.yml
P='sofa with cushions,black office chair,table,potted green plant,plain room wall,floor,flat white ceiling,table lamp,door,television screen,rug,wall clock,desk organizer'
FR=$(seq -s ' ' 0 6 294)
# 无先验（=基线）：--prior none；几何先验：
.venv/bin/python scripts/orb_slam/eval_geo_prior.py --config $CFG --ns data/office0_est320_ns \
  --gt-dir data/office0_est320/frames/semantic --prompts "$P" \
  --gt-ids 76 20 80 44 93 40 31 47 37 87 98 22 35 --frames $FR \
  --prior norm --geo-up 0 1 0 --geo-cos-thr 0.85 --dump-scores results/orb_ate/ab_amg/geo20_old \
  --out results/orb_ate/ab_amg/geo20_geo_miou.txt
# 叠加清理（激进；geo20_old/prompts.json 需先补 colors 键）：
.venv/bin/python scripts/orb_slam/cleanup_sem_maps.py --in-dir results/orb_ate/ab_amg/geo20_old \
  --out-dir results/orb_ate/ab_amg/geo20_old_clean \
  --wall-classes 4 --ceiling-classes 6 --extra-host-classes 5 \
  --min-area-frac 0.002 --merge-tiny \
  --gt-dir data/office0_est320/frames/semantic --gt-ids 76 20 80 44 93 40 31 47 37 87 98 22 35
```
