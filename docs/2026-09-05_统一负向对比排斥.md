## 0 结论速览

1. **机制全链路实现并跑通**：训练每步把高斯世界坐标 means 额外光栅成 ~3 通道位置图 → 每像素法向·up（`nx`）+ 每教师格世界平面拟合残差 → 与教师受限 argmax 的文本顶格合成锁定掩码 → 被锁格子的渲染特征对错误类别文本做 **hinge 负排斥**、正蒸馏 ×0。300 iter 冒烟 0 报错、无 NaN；TB 出 `sem_contrast` loss 与 `sem_contrast_locked_frac`（冒烟 0.6–0.72，早期特征未收敛故 hinge=0，符合预期）。
2. **nx 符号在真实数据上对照验证**：office0 GT ceiling 像素 mean nx −0.54…−0.77（负=朝下，与 `eval_geo_prior` 同约定）、floor 为正、wall ≈0 → 门控方向正确。
3. **全新增量默认 OFF**：17 个 `sem_contrast_*` config 字段默认关闭/空；OFF 时无额外光栅、无 loss、`get_loss_dict` 逐位同旧。文本嵌入复用教师显存中的 CLIP 塔（不新载 fp32 模型，避 8GB OOM），惰性缓存一次。
4. **office0 20k 双臂结果（§5）**：天花板 regime **核心假设成立** —— 训练期纯负向排斥把 plain-argmax ceiling 从 0.005 抬到 **0.217（A′）/ 0.205（A）**（geo oracle 0.249），**无需部署端仲裁**。但天花板 hinge 停泊漂移使 tv/door FP-on-stuff 翻倍（mIoU A′ 0.236）；flat regime 几何不适定 —— 真 flush 电视 recall 0.986→**0.619 崩**（mIoU A 0.243，为含打没真物的净平衡）。**结论：ceiling regime 干净可发，flat regime 保持默认 OFF**。

## 1 机制

**几何探雷（训练期，全 detach，梯度只进语义）**：语义 feature pass 内另做一次 `C=3` 光栅，`colors = means.detach()`（高斯世界坐标）→ 期望位置图 `sem_feature_pos [H,W,3]`（预乘 / α）。同一次 pass 的 α 作为几何覆盖。
- `surface_upness_from_pos`：replicate 补边 → 中心差分 → `cross` → 朝相机定向（训练用 `optimized_camera_to_world` 平移，与渲染视点一致）→ 归一 → `nx = n·up`。**逐字迁移** `eval_geo_prior.surface_upness`。
- `cell_plane_flatness`：位置矩量图池到教师格 `[gH,gW]` → 每格 3×3 协方差 → **`torch.linalg.eigh`**（对称阵永不上抛，替换回退版 `solve` 奇异崩溃点）→ `resid_rms=√最小特征值`；`flat = 覆盖充足 ∧ 两主向伸展(eig1≥ratio·eig2 且 eig2>1µm²) ∧ resid≤1cm`。rank-0（单大高斯=整格常数位置）与 1-D 细线都被伸展守卫拒掉。

**双 regime 掩码**（各在**自己的受限词表**上 argmax，不合并 union）：
- **天花板 regime**：教师受限 argmax ∈ {wall,floor,ceiling} 词表 = `plain room wall`（down-不可能）→ 且该格已覆盖像素中 `nx < −0.85` 占比 > 0.5 → 锁。锚 = wall 文本。
- **平斑 regime**：教师受限 argmax ∈ {tv,door,table lamp,wall clock} → 且该格平整 → 锁。锚 = 该 argmax 文本。

**Loss**：`L_contrast = mean_{locked} relu(cos(pred_n, anchor) − margin) · mult`；`semantic_loss` 域改为 `mask & ~locked`（已知错的老师目标不回灌）。`mask` 限定锁定只在教师监督域内（α>0.5 池化 ∧ cov>0.4）。

**预期效果**：天花板特征被推离 wall 文本 → 漂到合理停泊点 → 推理纯 argmax 落到 ceiling；墙斑被推离 tv/door 文本 → 与周围干净 wall 特征由既有 TV/蒸馏吸收。类别词**仅作排斥锚**，永不作正目标。

## 2 已定设计决策（用户拍板）

1. 几何来源 = **新增 ~3 通道世界坐标光栅**（非 view-space `sem_feature_depth`）；法向/平整度按 eval 原算法迁移。
2. 对比项 = **hinge + margin**：`max(0, cos(pred, anchor) − margin)`，margin 默认 0.2（本管线 CLIP 图↔文 cos 挤在 ~0.2–0.35 窄带）。
3. 被锁格子正 `semantic_loss` ×0（domain = `mask & ~locked`）。
4. 全部新 config **默认 OFF**；几何/掩码 detach；helper 全在 `losses.py`（模型无关、CPU 可测）。
5. 词表经 config CSV 注入、惰性文本编码一次，复用显存中 CLIP 塔。

### 5.3 判读（结论）

1. **天花板核心假设成立**：纯负向排斥（训练期、无部署仲裁）把 plain-argmax ceiling 从 0.005 抬到 **0.217（A′）/ 0.205（A）**，达到 geo oracle 0.249 的 ~85%。risk #1 回答：**不需要**查询期先验或 ceiling 正锚；纯负向足以让天花板特征落回 ceiling。这是本轮首要正面结果。
2. **ceiling-only（A′）的代价 = 停泊漂移**：hinge 一推离 wall 就停（margin 内无压），被推出墙文本的天花板像素**部分停靠到 tv/door 文本** → 真物 recall 保住（tv .983、door .996）但 **tv/door FP-on-stuff 翻倍**（788k→1.98M、1.32M→2.33M），tv/door/rug IoU 被 FP 压低 → mIoU 0.236 < reg。
3. **flat regime 几何上不适定（risk #2 实证）**：平斑 veto 无法区分"墙上的真电视"与"墙斑"（两者都平整、共面、教师读同一词），主动 hinge 把真 tv 一并推开 → **真 tv recall 0.986→0.619 崩**。flat 只有"排斥侧不在真物集合内"才安全 —— down-facing 排斥 wall（天花板 regime）安全正因 down-不可能为真 tv/floor；flatness 不构成"不可能"，故 flat regime **不建议部署**。其 FP 削减（door 857k ✓）不值得 tv recall 崩。
4. **A 的 mIoU 0.243 > A′ 0.236** 主要来自 wall 回吐（0.435→0.484）与 sofa 抬升，但这是**含 flat 把真物打没后的净平衡**，不是干净增益。

**下一步候选（未跑，需拍板）**：把天花板 regime 的 hinge 从"单锚 wall"扩成**多锚负排斥**（同时推离 wall/floor + tv/door/rug/lamp 等 stuff/thing 文本，仍纯负向、不引入正锚），专治 §5.3.2 的停泊漂移；ceiling regime 是干净的、可单发，flat regime 保持默认 OFF。

## 6 风险与决策点

1. **（已答，核心假设成立）** 纯负向把天花板抬回 ceiling：A′ plain-argmax ceiling 0.005→0.217，不需查询期仲裁，也未走 (a)–(c) 的 fallback。**残余问题**：hinge 单锚 wall、margin 内即停 → 部分被推离的天花板像素停靠到 tv/door/rug 文本（FP-on-stuff 翻倍）。候选解法 = **多锚负排斥**（同时推离 wall/floor + 各 stuff/thing 词，仍纯负向）——§5.3 下一步，未跑。
2. **（已答，flat regime 不适定）** 真 flush tv/door 与墙斑在几何+教师上不可分：真 tv recall 0.986→0.619 崩（A），印证"排斥侧必须在真物集合之外才安全"。flat regime 默认 OFF，不部署。真物 recall 由 `measure_thing_recall.py` 持续盯。
3. **空/退化格**：`eigh` 路径 + 覆盖/spread/rank0 守卫 + 回归测试（§3 测试 5/6/7）；`semantic_loss` 全锁空域守卫（返零）。已由 20k 双臂整跑无 NaN/无崩溃覆盖。
4. **几何/教师网格对齐**：同一 `adaptive_avg_pool2d(…,(gH,gW))`；`locked &= mask` 把 regime 限在教师监督域。20k 稳态 ~60 ms/步佐证无异常开销。
5. **（已观察）** A′ 正是"推离 wall → 停靠 tv/door"的交叉迁移实例（§5.3.2），hinge 有界但停靠点不受控；多锚/减 margin 是下一轮对症。
