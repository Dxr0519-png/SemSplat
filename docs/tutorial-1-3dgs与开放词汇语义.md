# 教程 1：3DGS 与「开放词汇语义 3DGS」——你做的到底是什么

> 对应项目：`semsplat`（整个插件）。读本文前建议先有图像/线性代数/一点点深度学习基础。
> 读完你能回答：高斯是什么、怎么"渲染"出图像、为什么要给高斯加语义、什么叫"开放词汇"。

## 0. 一句话

本项目想做的事：给一个 3D 场景建一张 **高斯地图**（每个高斯带颜色/几何），再给**每个高斯额外学一个低维"语义向量"**，让任意文本（"sofa"、"红色椅子"、"显示器"）都能去"点亮"地图里对应的东西。前者是 3D Gaussian Splatting (3DGS)，后者是「语义特征蒸馏」。

---

## 1. 第一部分知识：3D Gaussian Splatting

### 1.1 从体素/NeRF 到显式高斯

隐式神经辐射场（NeRF）用一个 MLP 存"空间的颜色/密度"，查询一个像素要沿光线采样几十个点 → 训练/渲染都慢。**3DGS** 反其道：把场景**显式**表示成一堆**三维高斯椭球**，每个高斯携带：

```
位置 μ (3)    旋转 R/四元数 q (4)    各向异性尺度 s (3)   不透明度 α (1)   颜色 c (3, 可更高阶用球谐SH)
```

几十万~几百万个高斯拼在一起，就能表达复杂场景。这很像"把点云变糊一点再拼颜色"。

> 每个"高斯"其实是一个 3D 概率密度：中心 μ、协方差 Σ = R S Sᵀ Rᵀ。它的数值表示该空间点对这个椭球的"占据/影响权重"。

### 1.2 光栅化（渲染）：3D → 2D 图像

要把 3D 高斯画到图像上：
1. **投影**：把 3D 高斯按相机参数投影成屏幕上的 2D 高斯（用视图变换 + 内参，含椭球透视近似）。
2. **排序**：把与当前像素相关的所有高斯按深度排序（近的在前）。
3. **α 混合**：像素颜色 = 逐层叠加

```
C = Σᵢ cᵢ · αᵢ · Tᵢ ,   Tᵢ = ∏_{j<i}(1 − αⱼ)   （前到后：不透明处会"挡住"后面的）
```

其中 αᵢ 是"该像素上这个高斯的覆盖量 × 高斯自身不透明度"。渲染出的每个像素同时带一个 **alpha（累计不透明度）**，用来判断"这里有没有几何"。

> 关键：**整条链是处处可微的**（投影、排序、混合都能回传梯度），所以能用梯度下降同时调所有高斯参数，让"渲染出的图"逼近"真实拍到的图"。

### 1.3 训练：它靠什么损失学几何

训练集 = 一批已知位姿的图片。每步随机取一张，渲染，算：
```
L = (1−λ)·L1(渲染, 真值) + λ·(1 − SSIM(渲染, 真值))
```
L1 保颜色绝对值、SSIM 保结构/局部对比。渲染出的像素要跟真值图片对齐，高斯就自动"挪到该在的地方、长得该有的样子"。

### 1.4 致密化：高斯会"分裂/复制/删除"

一开始高斯很少（随机点云/几百点初始化），不够表达细节。训练中每若干步：
- 看每个高斯的**屏幕空间位置梯度**：梯度大 = 它"想移动但盖不住"，就把它 **一分为二**（分裂）或**复制一个**（duplicate，按尺度大小区分）。
- 把透明度太低（不透明/没贡献）的删掉；周期性地把透明度重置低一点再重新长。
- 让新的高斯继承老高斯的所有属性。

这套"自适应致密化"让高斯数量随场景复杂度增长——这也是本项目里 `sem_features` 必须跟着高斯一起分裂/删除的原因（**教程 2** 详讲）。

## 2. 第二部分知识：把"语义"粘到高斯上

### 2.1 三种主流做法（帮你定位本项目）

给 3D 场景加语义，常见三类：

| 路线 | 代表 | 做法 | 优缺点 |
|---|---|---|---|
| **A. 逐高斯特征蒸馏** | **Feature-3DGS（本项目近似）** | 每个高斯存一个特征向量 f，用 2D 视觉大模型特征做"教师"监督它；查询=拿文本/特征去匹配 f | 简单、天然可光栅化到任意视图；质量取决于教师特征 |
| B. 语言场/自动解码器 | LangSplat 等 | 高斯存低维隐码，经小网络解码成 CLIP/SAM 语言特征；常用 SAM 掩码做区域级聚合 | 开放语义更准，但管线重（要 SAM 分割） |
| C. 语义标签直接回归 | Semantic 3DGS | 每个高斯存 one-hot 类别概率，有 2D 标签图监督 | 只能预测训练见过的类别（封闭集） |

本项目 = **路线 A**：轻量、无需 SAM，代价是稠密语义精度有限。

### 2.2 "教师"从哪来：2D 视觉大模型（CLIP）

人类要说一句"蓝色的椅子"就能从图里找到它，是因为脑子里有**图像和文字的共同概念空间**。机器版 = **CLIP**：
- 训练时拿「图片 + 它的文字描述」配对做对比学习，学会让"对应图文"的向量靠近、"不对应"的推远。
- 结果：**图片编码器输出 512 维向量、文本编码器输出同 512 维向量，且在这个空间里能互相比较**（点积/余弦 = 语义相似度）。

于是"开放词汇查询"的配方就是：
1. 把文本（任意词）编码成向量 t；
2. 把图像/3D 位置的语义也放进同一个空间，得向量 f；
3. `相似度 = cos(f, t)`，高的地方就是"文本描述的东西"。

因为词汇来自**共享文本空间而非固定类别表**，所以叫**开放词汇（open-vocabulary）**——不用预先定义 20 个类，你想问什么都行。

### 2.3 Feature-3DGS 式蒸馏：把 2D 特征"印"进 3D

Feature-3DGS 的核心 trick：
- 用一个冻结的 2D 大模型给**每张训练图**算出**逐像素/逐 patch 的特征图**（教师）。
- 训练时把高斯的特征向量也**光栅化成特征图**（学生），让两者在每处像素对齐：
```
L_sem = ‖ 渲染出的特征图 − 教师特征图 ‖（在对应的位置上）
```
- 由于高斯是可微光栅化的，这个损失会把梯度**只流回每个高斯的特征向量**，让"这个高斯代表的那个表面"自动学到"该表面在 2D 特征空间里的样子"。

**几何负责"在哪"，语义损失负责"这地方是什么"**，两者各司其职，这就是它高效的原因。

> Feature-3DGS 原论文为了让高维特征光栅化不慢，先把高斯存**低维 K**（本项目 K=32），渲染后再用一个**共享小网络/1×1 卷积**升到教师维度 M（512）。因为"池化"和"1×1 卷积"都是线性且可交换的，先池化再升维和先升维再池化结果一样 → 我们用 `nn.Linear(K,M)` 作为这个共享解码器。

### 2.4 为什么语义质量卡在"教师"上

路线 A 的上限 = 教师特征本身的质量：
- CLIP 的**整图向量**很准，但**逐 patch 的局部特征**并没有被显式训练成"稠密语义分割器"，所以会出现"整张图都像椅子标签"这类空间模糊（这也是为什么我们只承诺定性演示）。
- 想更准就要更强的稠密教师：LSeg（CLIP 做逐像素分割的版本）、SAM 掩码平均池化、或 DINOv2 辅助结构。项目已把教师抽象成可替换模块（`teacher_model_name`）。

## 4. 常见误区

- **"高斯是固体小球"**：它是连续的概率密度/模糊椭球，靠大量叠加 + 排序混合成像。
- **"语义是训练时分类出来的"**：不是。我们只让它"逼近 CLIP 特征"，到底像哪个词是查询时拿文本去比出来的。
- **"教师特征越多越好/维度越高越准"**：高维光栅化慢（gsplat D>32 性能下降），低维 + 解码头是工程平衡。
- **"语义损失也帮几何"**：默认 `detach` 几何（`semantic_detach_geometry=True`），语义损失只精修语义向量；几何靠 RGB 损失，避免互相干扰。
